Key findings (details in scorm-notes.md)
Player: Storyline in one iframe, iframe[title="Driver's License Renewal Course"], reached via /mod/scorm/player.php. Opening it takes about 15–25 s on dev.

Restart resets both the bookmark and the menu ticks/locks. The prompt appears on every relaunch.

Slides move on by themselves when they finish. In section 1:

only "Welcome" needs "next"
only "Speed Limits Based on Location" needs its in-slide CONTINUE
A player left open moves the account forward on its own, so exit promptly. One advanceSlide() call can pass several slides.

Slides take 10–26 s each.

CONTINUE is covered by its drawn picture, so it needs click({ force: true }).

"next" is disabled through aria-disabled="true" plus class cs-disabled. It looks enabled for a split second when the slide changes, so advanceSlide() only trusts it after 1 s and clicks with a 5 s timeout.

Slide title comes from the hidden #slide-label ("slide: <title>"). It can differ from the menu name, e.g. "Basic Speed Law (cont.)" sits under "About Basic Speed Law".

Menu state is the end of each item's accessible name: "X visited", "X locked" or "X visited, locked". Items in collapsed sections are hidden, so isLocked()/isVisited() match on data-slide-title. Titles repeat across sections, so pass { section }. There is a 7th section, "Signs".

Menu button is "Sidebar Toggle" (open by default at desktop size). The tabs are "Menu" and "Transcript".

SCORM 1.2 via window.API:

cmi.core.lesson_location is always empty; the bookmark is cmi.suspend_data.
cmi.core.lesson_status stays incomplete, and cmi.core.entry is resume.
Saving:

POST /mod/scorm/datamodel.php happens about once a minute, not per slide.
"Exit activity" also saves, but Playwright never sees that request.
Autoplay worked headless and headed. It also worked without the flag, because the Restart click counts as a user gesture.

Harmless error: pageerror: "The play() request was interrupted by a call to pause()" appears on every run. P5's health check (RF11) must ignore it.
